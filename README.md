# UPI Transaction Analysis Dashboard

## 📌 Project Overview

This project analyzes UPI transaction data using **Microsoft Excel** to understand transaction trends, payment behavior, and overall transaction performance.

An interactive dashboard was created using **Pivot Tables, Pivot Charts, Slicers, and KPI Cards** to present the analysis clearly.

## 🛠️ Tools & Techniques

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Data Analysis
- Data Visualization

## 📊 Key KPIs

- **Total Transactions:** 5,02,887
- **Total Transaction Amount:** ₹44.25 Cr
- **Total Cashback:** ₹34.63 L
- **Success Rate:** 91%
- **Suspected Fraud:** 17,089

## 📈 Dashboard Analysis

The dashboard provides insights into:

- Transaction Amount by Day
- Transactions by UPI App
- Transaction Status
- Transaction Amount by State
- Transaction Amount by Bank
- Transaction Amount by Transaction Type
- Transaction Amount by Hour
- City-wise transactions
- Gender-wise transactions
- Merchant-wise analysis
- Merchant Category analysis

## 🎯 Key Insights

- Identified transaction patterns across different hours and days.
- Compared transaction amounts across different banks and states.
- Analyzed the performance of different UPI applications.
- Compared successful, failed, pending, and refunded transactions.
- Identified transaction types contributing the highest transaction amount.
- Analyzed suspected fraud transactions.
